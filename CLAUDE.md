# ctxhead

## Goal

Open-source npm CLI (`ctxhead`) that adds a frontmatter header summary to each source file so AI agents read ~15 lines instead of whole files, with body-hash staleness checks. It installs a skill, command, and rules block into Claude Code, Codex, Gemini CLI, and Antigravity.

## Source of truth

Linear project: https://linear.app/vijay-gangatharan/project/vs-code-ctxhead-bab97998c8e6

## Status

v1 implemented under openspec/changes/ctxhead-cli-v1 (archived). Planning lives in openspec/.

- `pnpm build` / `pnpm typecheck` / `pnpm lint` / `pnpm test`
